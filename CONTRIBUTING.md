## 🚀 Как начать

### 1. Форкни репозиторий
Нажми кнопку **Fork** на странице репозитория.

### 2. Клонируй и настрой
```bash
git clone https://github.com/YOUR_USERNAME/Anonka.git
cd Anonka
git remote add upstream https://github.com/Mukller/Anonka.git
```

### 3. Создай ветку
```bash
git fetch upstream
git checkout -b feature/description upstream/main
```

**Правила именования веток:**
- `feature/name` — новые функции
- `bugfix/name` — исправление ошибок
- `docs/description` — документация
- `refactor/description` — рефакторинг

## 💻 Стиль кода
- Следуй PEP 8 для Python
- Используй понятные имена переменных и функций
- Комментарии на русском или английском

## 📝 Коммиты
```bash
git commit -m "feat: Add new feature"
git commit -m "fix: Correct bug"
git commit -m "docs: Update README"
```
**Типы:** `feat`, `fix`, `docs`, `refactor`, `test`, `perf`

## 🔄 Pull Requests

1. ✅ Убедись, что код работает корректно
2. ✅ Обновись с `upstream/main`
3. ✅ Создай PR с описанием изменений

## ❓ Вопросы?
Создай [Issue](https://github.com/Mukller/Anonka/issues) с пометкой `question`.

## 🚀 Getting Started

### 1. Fork the repository
Click the **Fork** button on the repository page.

### 2. Clone and setup
```bash
git clone https://github.com/YOUR_USERNAME/Anonka.git
cd Anonka
git remote add upstream https://github.com/Mukller/Anonka.git
```

### 3. Create a branch
```bash
git fetch upstream
git checkout -b feature/description upstream/main
```

**Branch naming:**
- `feature/name` — new features
- `bugfix/name` — bug fixes
- `docs/description` — documentation
- `refactor/description` — refactoring

## 📝 Commit Messages
```bash
git commit -m "feat: Add new feature"
git commit -m "fix: Correct bug"
```

## 🔄 Pull Requests

1. ✅ Ensure code works correctly
2. ✅ Sync with `upstream/main`
3. ✅ Create PR with a clear description

## ❓ Questions?
Open an [Issue](https://github.com/Mukller/Anonka/issues) labeled `question`.
